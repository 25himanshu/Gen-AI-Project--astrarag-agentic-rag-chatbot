# 🤖 AstraRAG – Agentic RAG Chatbot

### Intelligent Retrieval. Autonomous Reasoning. Context-Aware Answers.

AstraRAG is an AI-powered Agentic RAG chatbot designed to deliver intelligent, context-aware responses by combining Retrieval-Augmented Generation (RAG) with AI agent capabilities. It aims to improve information retrieval, understand user queries, and generate relevant answers using external knowledge sources.

## 🚀 Key Features

- **Agentic AI:** Uses AI agent capabilities to support intelligent query handling.
- **Retrieval-Augmented Generation (RAG):** Retrieves relevant information before generating responses.
- **Context-Aware Responses:** Generates answers based on retrieved knowledge.
- **Intelligent Query Processing:** Understands user questions and identifies relevant information.
- **Conversational Interface:** Enables interactive communication with the AI chatbot.
- **Knowledge-Based Responses:** Reduces reliance on general model knowledge by incorporating external information sources.

## ⚙️ How It Works

1. The user submits a question through the chatbot interface.
2. The AI agent processes the query and determines the required information.
3. The retrieval component searches relevant external knowledge sources.
4. Retrieved information is passed to the language model.
5. The LLM generates a context-aware response.
6. The chatbot presents the answer to the user.

## 💻 Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/25himanshu/project-3-astrarag-agentic-rag-chatbot.git
```

**2. Navigate to the project directory**

```bash
cd project-3-astrarag-agentic-rag-chatbot
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Configure environment variables**

Create a `.env` file and add the required API keys and configuration values.

```env
API_KEY=your_api_key_here
```

Never upload API keys, passwords, or secrets to GitHub.

**5. Run the application**

Use the appropriate command based on your project's framework and entry-point file.
